# Security policy

Inference Server Lab is an educational project and must not be exposed as a production service or
to untrusted traffic. It intentionally omits parts of the authentication, authorization, isolation,
rate limiting, dependency hardening, and incident response expected in production.

Report suspected vulnerabilities privately with a GitHub Security Advisory for this repository.
Do not open a public issue containing exploit details, credentials, tokens, private model data, or
personal information. Include the affected commit, reproduction steps, impact, and any suggested
mitigation. Maintainers will acknowledge a report when available; this volunteer project makes no
response-time guarantee.

Course mistakes, confusing explanations, and non-sensitive bugs belong in the public issue forms.
